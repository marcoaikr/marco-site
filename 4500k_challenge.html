지도가 채워질수록, 우리는 대한민국을 달립니다

부산 오륙도에서 출발해 남해안·서해안·DMZ·동해안을 잇는 코리아둘레길 4,500km를 하루 150km씩 30구간으로 나눴습니다. 구간을 누르면 그날 함께 달린 러너 30명을 만날 수 있어요.

구간별 러너 · DAY 21

아래 30개 구간에서 원하는 날을 눌러보세요.

How to join

참여는 딱 4단계, 러닝 기록이 없어도 됩니다

완주 실력도, 대회 기록도 필요 없어요. 오늘 5km를 걷거나 뛰고, 인증만 하면 대한민국 지도의 한 칸이 당신 덕분에 채워집니다.

1

5km 달리기

동네 어디서든 좋아요. 러닝앱·워치·스크린샷으로 오늘의 5km를 기록합니다.

2

인스타 인증

러닝 기록과 함께 게시물을 올리고 아래 두 해시태그를 답니다.

#청춘양말 #4500kchallenge
3

거리 누적

청춘양말이 해시태그를 확인해 이 지도에 당신의 5km를 더합니다. 실시간으로 채워져요.

4

혜택 받기

매일 선착순 30명은 5K START 무료 증정, 그 외 인증자 전원에게도 협찬사 제품이 갑니다.

Rewards

선정돼도, 안 돼도 — 참여하면 손해가 없습니다

이 챌린지의 진짜 후크는 지도가 아니라 “참여하면 받는다”입니다. 40년 제조사 청춘양말과 협찬사가 함께 준비했어요.

🎁 매일 선착순 30명 · 총 900명

오늘의 30자리

그날 가장 먼저 인증한 30명에게
  • ✓5K START 러닝양말 무료 증정 (MIX RUN 에디션)
  • ✓디지털 러너 카드 발급 — 내 거리·순위가 담긴 공유용 카드
  • ✓명예의 전당 등재 + 웹 지도에 내 인스타 아이디 노출
  • ✓10K RUN 라인 우선 체험 초대
🤝 인증한 누구나

참여자 전원

30자리에 못 들어도 빈손은 없습니다
  • ✓협찬사 제품 제공 — 러닝 굿즈·음료·소모품 등 (선착순 소진 시까지)
  • ✓내 5km가 누적 거리에 그대로 반영 · 웹 지도 기여자 등재
  • ✓다회 인증·다른 러너 응원 시 PACER 뱃지 + 5K STARTER SET 할인
  • ✓친구 초대하고 함께 뛰면 둘 다 추가 혜택 (친구 초대 리워드)
